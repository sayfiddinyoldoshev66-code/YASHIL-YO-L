07 — Texnik jihatlar

Arxitektura va texnologiyalar

Nega tashqi kutubxonasiz?

Loyiha bitta HTML fayl — internet bo‘lmasa ham ishlaydi, yuklanish tez, kichik hajm.

JavaScript qayerda ishlatilgan?

Xaritani dinamik qurish, narx hisoblash (Intl.NumberFormat), scroll-reveal (IntersectionObserver), mobil menyu.

CSS yondashuvi

Flexbox va Grid, custom properties bilan yagona dizayn tizimi, media queries bilan to‘liq responsive.

Mavjudlik (accessibility)

Semantik HTML, aria-expanded bilan boshqariladigan menyu, kontrastli ranglar.
